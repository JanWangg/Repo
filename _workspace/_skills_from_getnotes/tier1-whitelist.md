## ❌ 黑名單（永遠不採用）

- 知乎
- 微信公眾號
- 百度百科 / 百度知道
- 未署名的內容農場
- 沒有原始來源的「業內傳言」

## 來源使用原則

1. **單一事實優先 Tier 1**：HBM 市佔、CoWoS 產能 → 用公司 IR
2. **市場預測優先 Tier 2**：設備市場、記憶體 ASP → 用 TrendForce/SEMI
3. **新聞觸發優先 Tier 3**：事件驅動的頭條 → 用 Reuters/FT，但要找到 Tier 1/2 原始數字
4. **跨來源驗證**：關鍵數字（缺口%、市佔率）至少要有 2 個來源
5. **時效性**：設備/記憶體市場數據需 < 3 個月，財報數據需 < 1 季
