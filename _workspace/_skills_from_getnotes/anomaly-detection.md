# 異常偵測 SOP（v6.1 新增）

> 自動化品質控制 — 防止「垃圾進、垃圾出」

## 🎯 三層異常偵測

### Layer 1：來源矛盾偵測

**觸發**：同一指標，兩個 Tier 1 來源數字差異 >5%

**範例**：
- TSMC 公告 CoWoS 2026 底 105K WPM
- Digitimes 報導 95K WPM
- 差異 = (105-95)/95 = 10.5% > 5% → 🔴 觸發

**處理**：
1. 標記為「來源矛盾」
2. 取較保守數字（較低產能、較高需求缺口）
3. 在晨報的「異常警示」區塊註明

---

### Layer 2：時序偏移偵測

**觸發**：與昨日對比，關鍵指標變化 >10%

**範例**：
- 昨日 HBM4 ASP $25-30/GB
- 今日現貨 $20/GB
- 變化 = -25% > 10% → 🔴 觸發

**處理**：
1. 標記為「重大偏移」
2. 追溯到具體新聞/IR 更新
3. 評估是否需要修正 M4 模型預設值

---

### Layer 3：模型內部一致性

**觸發**：M2-M5 之間出現邏輯矛盾

**範例**：
- 🔴 M2 CoWoS 缺口 -9%（收斂中）
- 🟢 M3 設備交期 < 12 月（鬆）
- 🟢 M4 HBM 售完狀態解除
- → 三個指標都顯示超級週期接近尾聲，但 M5 彈性仍維持 2.5x → 模型不一致警示

**處理**：
1. 重新檢查每個模型的數據來源時效
2. 評估是否為「領先指標尚未反映」
3. 在晨報加註「模型一致性警示」
