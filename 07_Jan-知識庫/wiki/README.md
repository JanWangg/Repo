## 🚦 快速開始

**你是第一次來？**
1. 讀 `index/Hermes-Digital-Brain-MOC.md`（主入口）
2. 認識 6 座宮殿 `entities/memory-palace/`
3. 挑一個心智模型開始用 `entities/mental-models/`

**想找特定內容？**
- 某個概念 → 看 `index/MOC-Knowledge-Domains.md`
- 某個思維工具 → 看 `index/MOC-Mental-Models.md`
- 某個主題長文 → 看 `topics/`

**想記錄新東西？**
- 領悟 → 用 `templates/Insight-Template.md` → 放 `synthesis/insights/`
- 決定 → 用 `templates/Decision-Template.md` → 放 `synthesis/decisions/`

## 🔗 連結規則

- 所有 `.md` 檔案間使用 Obsidian `[[雙連結]]`
- 跨領域引用必須打 Tag（見 `index/MOC-Tag-Guide.md`）
- 重要內容至少要連結到「一座宮殿 + 一個領域 + 一個心智模型」
