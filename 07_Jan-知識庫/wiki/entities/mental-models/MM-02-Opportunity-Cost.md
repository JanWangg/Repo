# 機會成本 💰

> **選擇 = 放棄其他可能**
> 經濟學最根本的概念，卻是大多數人最容易忽略的。

## 一句話定義
每一次選擇都有成本 — 成本是「放棄的最佳替代方案」的價值。

## 適用場景
- ✅ 時間配置（該做 A 還是 B？）
- ✅ 資金配置（該買 X 還是 Y？）
- ✅ 注意力配置（該學領域 1 還是 2？）
- ❌ 無可替代的唯一選擇（機會成本 = 0）

## 操作步驟

```
1. 列出所有可選方案
2. 評估每個方案的預期價值
3. 找出「次佳方案」 — 這就是機會成本
4. 比較「當前選擇」 vs 「次佳方案」的差價
5. 如果差價 < 0，重新考慮
```

## 數學表達

```
機會成本 = max(其他方案的預期價值)
選擇的淨價值 = 當前方案價值 - 機會成本
```

## Jan 的應用案例

- **學習時間**：與其讀完一本書，是否該先寫一篇讀書心得輸出？
- **投資**：與其加碼台積電，是否該佈局「次佳選擇」（如 ASML）？
- **AI 專案**：與其自己寫代碼，是否該用現成框架？

## 常見誤用

- ❌ 把「沉沒成本」當機會成本（已花費的時間/金錢不能回收）
- ❌ 用「我喜歡」忽略機會成本（情感不應掩蓋經濟現實）
- ❌ 只算金錢不算時間（時間是更稀缺資源）

## 與其他模型的關係
- → 是**期望值**的姐妹概念（期望值算收益，機會成本算代價）
- → 是**TOC 瓶頸理論**的資源分配依據
- → 是**複利效應**的時間版本（時間的機會成本最貴）
