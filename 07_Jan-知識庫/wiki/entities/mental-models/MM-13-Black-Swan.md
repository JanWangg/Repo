# 黑天鵝 🦢

> **為不可預測事件做準備**
> 納西姆·塔勒布：「世界由極少數的極端事件決定。」

## 一句話定義
**不可預測、影響巨大、事後編造理由**的事件。
COVID-19、911、次貸危機，都是黑天鵝。

## 三大特徵

```
1. 不可預測（Outlier）
   → 事前沒有任何模型預測到
2. 影響巨大（Massive Impact）
   → 改變歷史走向
3. 事後合理化（Retrospective Predictability）
   → 事後人人都說「早就知道」
```

## 三大原則

```
1. 脆弱者被摧毀，強健者存活，反脆弱者獲益
   → 黑天鵝發生時，誰還活著？誰能從中獲利？

2. 不要預測，要準備
   → 預測黑天鵝 = 浪費時間
   → 準備應對黑天鵝 = 投資報酬率最高

3. 過度暴露於正向黑天鵝 = 必然被負向擊中
   → 過度槓桿、長期滿倉、過度集中 = 風險暴露
```

## 應對策略

| 策略 | 具體做法 |
|------|---------|
| **降低脆弱性** | 去槓桿、保留現金、分散資產 |
| **建立冗餘** | 多地備份、多元收入、Plan B |
| **購買保險** | 保險、避險、選擇權 |
| **啞鈴策略** | 90% 極保守 + 10% 極激進 |
| **反脆弱設計** | 讓系統從衝擊中獲益 |

## Jan 的應用案例

- **投資組合**：永遠不滿倉，保留 20-30% 現金
- **AI 系統**：API 故障時的降級方案
- **知識管理**：多地備份（雲端 + 本地）
- **生活**：保險、應急基金、人脈網絡

## 常見誤用

- ❌ 把「小機率事件」當黑天鵝（黑天鵝真實機率極低）
- ❌ 過度防備（犧牲效率只為防禦）
- ❌ 忽略正面黑天鵝（意外的好事也存在）

## 與其他模型的關係
- → **安全邊距**的應用場景
- → **反脆弱**的目標（從黑天鵝中獲益）
- → **風險矩陣**的補充（風險矩陣處理已知風險，黑天鵝處理未知）
