# 第一性原理 🧬

> **回到事實本身，從頭推理**
> 馬斯克：「大多數人是類比推理（看別人怎麼做就跟著做），第一性原理是拆解到不可再分的基本事實，再重新組合。」

## 一句話定義
不從既有結論/類比出發，而是拆解到**不可再分的基礎事實**，從事實重建推論。

## 適用場景
- ✅ 看似無解的問題（成本過高、技術不存在）
- ✅ 需要顛覆式創新
- ✅ 驗證「大家都這樣做」的合理性
- ❌ 已有成熟 SOP 的執行性工作

## 操作步驟（5 步）

```
1. 定義問題 → 我真正要解決什麼？
2. 拆解要素 → 拆到不可再分的物理/邏輯事實
3. 質疑假設 → 每個假設都問「為什麼這樣？」
4. 重建推論 → 從事實重新組合解決方案
5. 驗證 → 與現實對照，迭代修正
```

## 經典範例：SpaceX 火箭

```
傳統推理：火箭成本 6500 萬美元，因為市場就是這個價。
第一性原理拆解：
  火箭材料 = 鋁、鈦、銅、碳纖維
  → 這些材料的市場價 = 火箭成本的 2%
  → 因此 98% 的成本是流程/組織效率問題
  → SpaceX 自製 → 成本降到 10%
```

## Jan 的應用案例

- 知識管理：質疑「為什麼需要 17 個 KB」→ 拆解到「知識輸入/加工/輸出」三層
- 投資：質疑「為什麼該投資某公司」→ 拆解到護城河/財務/估值
- 系統設計：質疑「為什麼需要某功能」→ 拆到使用者痛點

## 常見誤用

- ❌ 「這是第一性原理思考」其實只是換個說法（沒有真正拆解）
- ❌ 過度拆解導致決策延宕
- ❌ 拆解時漏掉隱性假設（如組織文化、激勵機制）

## 與其他模型的關係
- ← 與**逆向思考**互補（從失敗往前推 vs 從事實往後推）
- → 是**系統思維**的起點（先拆解到要素，再看見結構）
- → 是**期望值**的基礎（先有正確的機率，才有期望值）
