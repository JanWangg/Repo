# 逆向思考 🔄

> **想避免失敗，比想成功更有用**
> 查理·芒格：「反過來想，總是反過來想。」

## 一句話定義
不直接想「如何成功」，而是先想「如何失敗」→ 避開失敗路徑。

## 適用場景
- ✅ 重大不可逆決策（投資/婚姻/職涯）
- ✅ 長期規劃（30 年後我不想變成什麼？）
- ✅ 規避已知的「死亡之谷」

## 操作步驟

```
1. 設定目標（正向）
2. 反向：定義「完全失敗」是什麼樣子？
3. 列出所有可能導致失敗的原因
4. 設計預防措施（針對每個失敗原因）
5. 執行 + 持續監控失敗信號
```

## 經典範例

**正向：** 「如何賺大錢？」
**逆向：** 「如何保證虧光？」→ 不懂不投、滿槓桿、聽明牌、all-in → 反過來避開

**正向：** 「如何建立成功的知識管理系統？」
**逆向：** 「如何讓系統崩潰？」→ 雜亂無章、過度複雜、無人維護 → 反過來設計

## Jan 的應用案例

- **投資逆向**：「這筆交易最壞會怎樣？」（先評估 downside）
- **AI 專案逆向**：「什麼會讓專案失敗？」→ 不明確需求/技術債/溝通 → 反推 SOP
- **知識管理逆向**：「什麼會讓 Wiki 變成垃圾場？」→ 不連結、不更新、過度分類 → 反推原則

## 常見誤用

- ❌ 只停留在「不要失敗」，沒轉回「如何成功」
- ❌ 列了一堆失敗原因但不行動
- ❌ 過度悲觀（避免失敗不等於悲觀）

## 逆向對價（閱讀投資觀）

> **先問「不讀會怎樣」，比問「讀了有什麼用」更有用。** — 芒格式逆向應用

- 用逆向思維審視每一次輸入：先問「讀完後**不做什麼**會怎樣？」
- 若答案是「不做也不會怎樣」→ 純消費，機會成本 = 你放棄了能產出對價的時間
- 若答案是「不做會虧」→ 真對價，這篇值得繼續投入

**判斷 3 問：**
1. 不讀這篇，我會錯過什麼具體的決策？
2. 讀完這篇，我會做出什麼不同的事？（用 30 秒說得出來嗎？）
3. 100 字能總結這篇的核心論點嗎？（不能 = 還沒讀懂）

**應用：**
- 投資研究報告 → 對價 = 持倉調整決策
- 晨報閱讀 → 對價 = 行動意圖登記
- 技術文檔 → 對價 = SOP 化輸出

**與其他模型的關係：**
- → **機會成本**是對價的姐妹概念（機會成本算代價，逆向對價算「不對價的代價」）
- → **OODA 環**的「觀察→定位」階段可用此框架過濾輸入


## 與其他模型的關係
- → **第一性原理**的姐妹（從事實出發 vs 從失敗出發）
- → **期望值**的另類算法（先算最壞情況的 EV）
- → **安全邊際**的思維來源（避免破產才有機會成功）
