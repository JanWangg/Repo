# 風險矩陣 📊

> **機率 × 影響 = 風險值**
> 任何決策前的標準動作。

## 一句話定義
用「機率」和「影響」兩個維度，把風險排序，優先處理**高機率 × 高影響**的紅區。

## 矩陣圖

```
              影響（Impact）
              低      中      高
         ┌──────┬──────┬──────┐
   高機率 │ 黃區 │ 橘區 │ 🔴紅區 │ ← 立即處理
         ├──────┼──────┼──────┤
   中機率 │ 綠區 │ 黃區 │ 橘區 │ ← 持續監控
         ├──────┼──────┼──────┤
   低機率 │ 綠區 │ 綠區 │ 黃區 │ ← 記錄即可
         └──────┴──────┴──────┘
```

## 適用場景
- ✅ 任何新計畫/專案的風險評估
- ✅ 投資組合的健康檢查
- ✅ 個人重大決策（換工作、結婚、置產）

## 操作步驟

```
1. 列出所有風險（腦力激盪，不評估）
2. 為每個風險評估「機率」（高/中/低）
3. 為每個風險評估「影響」（高/中/低）
4. 落入矩陣對應位置
5. 為每個紅區/橘區設計對策
6. 定期回顧更新
```

## Jan 的應用案例

- **AI 專案**：資料風險/技術風險/時程風險/外部風險
- **投資**：系統風險/個股風險/流動性風險/匯率風險
- **個人決策**：財務風險/家庭風險/職涯風險/健康風險

## 常見誤用

- ❌ 機率/影響判斷過於樂觀（規避偏誤）
- ❌ 只看紅區忽略綠區（綠區可能變黃）
- ❌ 不設定量化標準（「高」到底是什麼？）

## 與其他模型的關係
- → **期望值**的具體計算（機率 × 影響 = EV 的基礎）
- → **安全邊際**的決策依據（高風險區須有更大邊際）
- → **黑天鵝**處理矩陣外的事件（極低機率 × 極高影響）
