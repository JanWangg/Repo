# PDCA 循環 🔄

> **計劃→執行→檢查→行動 → 持續改進的飛輪**
> 戴明環（Deming Cycle），品質管理的基石。

## 一句話定義
任何改進都應經過 4 階段：計劃（Plan）、執行（Do）、檢查（Check）、行動（Act），形成**螺旋上升的飛輪**。

## 4 階段詳解

```
P（Plan）計劃：
  - 目標是什麼？
  - 假設是什麼？
  - 成功指標？
  - 風險預案？

D（Do）執行：
  - 小規模試點（pilot）
  - 收集過程數據
  - 不急於大規模推廣

C（Check）檢查：
  - 結果 vs 預期
  - 偏差在哪？
  - 為什麼會偏差？

A（Act）行動：
  - 標準化成功部分
  - 修正失敗部分
  - 進入下一輪 PDCA
```

## 適用場景
- ✅ 任何需要持續改進的流程
- ✅ 個人習慣養成
- ✅ 系統優化
- ❌ 一次性事件（無法形成迴路）

## Jan 的應用案例

- **晨報系統**：P 設定關注指標 / D 每天生成 / C 比對預期 / A 調整模型
- **投資組合**：P 設定配置 / D 執行交易 / C 季度檢視 / A 再平衡
- **知識管理**：P 設定攝入計劃 / D 蒸餾 / C 質量檢查 / A 更新 SOP

## 常見誤用

- ❌ 只 P 不 C（沒有回頭檢查）
- ❌ C 後不 A（發現問題不行動）
- ❌ PDCA 週期太長（一年一次就太慢）
- ❌ 把 PDCA 當形式（沒有實際決策依據）

## 與其他模型的關係
- ← **系統思維**的微觀實踐
- → **貝氏思維**是 Check 階段的工具
- → **第一性原理**是 Plan 階段的起點

## 延伸閱讀

- 今井正明《改善》（Kaizen）
