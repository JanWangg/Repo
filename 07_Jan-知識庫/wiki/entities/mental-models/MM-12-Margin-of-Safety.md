# 安全邊際 🛟

> **永遠留 30% 緩衝**
> 巴菲特：「安全邊際是投資的基石。」

## 一句話定義
**只買價值遠低於價格的東西**。低估時買入，給自己留犯錯空間。

## 三大應用領域

### 1. 投資
```
內在價值 = 100 元
買入價格 =  60 元（折價 40%）
安全邊際 = 40%
→ 即使判斷錯誤，價格跌 30% 仍安全
```

### 2. 工程
```
設計承重 = 1000 kg
實際負載 =  300 kg
安全邊際 = 70%
→ 地震/老化時仍有餘量
```

### 3. 時間/能量
```
預估工時 = 10 小時
實際排程 = 15 小時（含 50% 緩衝）
安全邊際 = 50%
→ 避免 delay 整個系統
```

## 適用場景
- ✅ 所有不可逆決策
- ✅ 預估任何時間/成本/資源
- ✅ 系統容量規劃

## 操作原則

```
1. 估計最可能的結果
2. 估計最壞的可能結果
3. 確保「最壞」也可承受
4. 如果不可承受，降低暴露
```

## Jan 的應用案例

- **投資**：持倉 < 80% 滿倉，永遠留現金
- **AI 系統**：API 配額 60% 警戒線
- **專案排程**：預估時間 × 1.5 = 真實排程
- **數據安全**：多地備份 + 加密

## 常見誤用

- ❌ 過度追求效率（消除所有緩衝）→ 一次意外就崩潰
- ❌ 估計過於樂觀（安全邊際小於實際風險）
- ❌ 將安全邊際視為浪費（其實是保命錢）

## 與其他模型的關係
- ← **反脆弱**的前提（沒邊際就沒反脆弱）
- → **黑天鵝**的應對（事件發生時仍存活）
- → **期望值**的修正項（EV 須考慮最壞情況）
