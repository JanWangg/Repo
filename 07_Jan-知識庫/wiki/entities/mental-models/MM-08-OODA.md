# OODA 循環 ⚡

> **觀察→定位→決策→行動 → 在不確定中搶得先機**
> 源自韓戰美軍空戰經驗，由 John Boyd 上校提出。

## 一句話定義
在不確定的環境中，**比對手更快完成 OODA 循環**就是最大戰略優勢。

## 4 階段

```
O（Observe）觀察：
  - 收集所有可得的資訊
  - 區分「事實」與「敘事」

O（Orient）定位：
  - 在自己的知識框架中定位這個資訊
  - 套用心智模型（文化/經驗/遺傳/分析）
  - 這是最關鍵、也最容易被低估的階段

D（Decide）決策：
  - 選擇行動方案
  - 即使不完美也要決定

A（Act）行動：
  - 執行
  - 觀察反饋
  - 進入下一輪 OODA
```

## 為何「定位」是關鍵？

```
大多數人以為 OODA 是：
  觀察（20%） → 定位（10%） → 決策（20%） → 行動（50%）

實際上是：
  觀察（10%） → 定位（60%）→ 決策（10%） → 行動（20%）

定位品質決定一切 — 心智模型豐富的人判斷更準
```

## 適用場景
- ✅ 高頻變化的環境（交易/創業/戰爭）
- ✅ 比速度比規模重要的場景
- ❌ 慢思考的哲學研究（不適合）

## Jan 的應用案例

- **晨報應對**：O 收集新聞 / O 定位於投資組合 / D 決定加減倉 / A 執行
- **AI 專案迭代**：O 用戶反饋 / O 定位於產品藍圖 / D 決定改什麼 / A 開發
- **生活應變**：O 突發狀況 / O 評估資源 / D 決定優先 / A 處理

## 常見誤用

- ❌ 跳過 O 直接 D（憑直覺行動，沒有定位）
- ❌ O 太久變分析癱瘓
- ❌ A 後不回頭 O（斷了迴路）

## 齒輪協同（OODA × 四齒輪同步咬合）

> **讀/寫/智/情 = OODA 環在閱讀系統的具體應用。**

OODA = 觀察(O) → 定位(O) → 決策(D) → 行動(A) → 形成閉環。
應用到閱讀四齒輪：
- **讀 = 觀察**：被動接收素材
- **寫 = 定位**：把觀察轉成可驗證的論點
- **智 = 決策**：從論點推導行動
- **情 = 行動**：把決策落到實踐，產生新觀察

**齒輪咬合示意：**
```
    讀(觀察) ──→ 寫(定位)
    ↑              ↓
    情(行動) ←── 智(決策)
         ↓
       閉環 = 飛輪
```

**典型斷裂模式：**
- 讀死書：只觀察不定位 → 智識空洞
- 寫死字：只定位不決策 → 寫作倦怠
- 想死路：只決策不行動 → 紙上談兵
- 做死功：只行動不觀察 → 原地打轉

**與其他模型的關係：**
- → **PDCA**是 OODA 的慢速版本（PDCA 強調整個週期，OODA 強調速度）
- → **系統思維**提供齒輪咬合的整體觀


## 與其他模型的關係
- ← **PDCA**的快速版（PDCA 慢，OODA 快）
- → **貝氏思維**是 O 階段的工具
- → **逆向思考**是 O 階段的另一個視角
