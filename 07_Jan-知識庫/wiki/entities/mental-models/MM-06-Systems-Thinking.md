# 系統思維 🔁

> **看見迴路、延遲、湧現**
> 真正的高手不是解決問題，是看見問題所在的系統。

## 一句話定義
世界不是線性的因果，而是**迴路**（增強/調節）+ **延遲** + **層級**構成的動態系統。

## 核心概念

```
增強迴路（Reinforcing Loop）：富者愈富（M型社會）
調節迴路（Balancing Loop）：體溫調節（負回饋）
延遲（Delay）：今天種樹 20 年後乘涼（容易被忽略）
湧現（Emergence）：整體 > 部分之和（自組織現象）
槓桿點（Leverage）：小改動觸發大變化
```

## 適用場景
- ✅ 複雜問題（社會/組織/生態）
- ✅ 長期策略規劃
- ✅ 個人成長（習慣系統）

## 冰山模型（4 層）

```
事件（Event）          ← 我們看到的「症狀」
  ↑
模式（Pattern）        ← 趨勢、週期
  ↑
結構（Structure）      ← 系統迴路、規則
  ↑
心智模式（Mental Model）← 系統設計者的信念
```

## 操作步驟

```
1. 看見事件（症狀）
2. 找出模式（重複出現）
3. 挖掘結構（什麼規則導致這個模式）
4. 挑戰心智模式（為什麼這個結構被設計出來？）
5. 找槓桿點（最小改動最大效果的位置）
6. 設計干預方案
```

## Jan 的應用案例

- **投資系統**：不只買個股，看見「宏觀 → 產業 → 公司」三層結構
- **知識管理**：不只收集資料，看見「輸入 → 加工 → 輸出」系統
- **AI 系統**：不只訓練模型，看見「數據 → 模型 → 應用 → 反饋」迴路

## 常見誤用

- ❌ 把「複雜因果」當「隨機」（其實是延遲的迴路）
- ❌ 只想解決事件，不想改結構（治標不治本）
- ❌ 在低槓桿點浪費力氣

## 與其他模型的關係
- ← **第一性原理**拆解要素，本模型看見要素間的關係
- → **E→P→S→M→L→A 框架**是系統思維的具體操作版
- → **PDCA**是系統思維在執行層的體現
