# 貝氏思維 🔄

> **用新證據更新信念**
> 不是「我對了/錯了」，而是「我的信念應該改變多少？」

## 一句話定義
信念不是固定的，而是隨證據動態調整的機率分佈。
P(新信念|證據) = P(證據|新信念) × P(新信念) / P(證據)

## 適用場景
- ✅ 觀點會被新資訊挑戰時（投資/技術/醫學）
- ✅ 想要避免「確認偏誤」
- ❌ 證據本身有偏（garbage in, garbage out）

## 操作步驟（4 步）

```
1. 設定先驗信念（Prior）— 我目前相信什麼？
2. 評估新證據（Evidence）— 證據強度多強？
3. 計算後驗信念（Posterior）— 信念該調整多少？
4. 重複 — 持續根據新證據更新
```

## 直覺範例

```
假設：某股票有 30% 機率上漲（Prior）
新證據：CEO 突然買進自家股票（市場強烈信號）

貝氏更新：
  → 機率從 30% 上升到 60%（取決於歷史基率）

再新證據：宏觀經濟轉差
  → 機率從 60% 降到 45%

結論：信念隨證據動態調整，不是死守 30% 或 100%
```

## Jan 的應用案例

- **投資觀點**：先有核心持倉，新證據（業績/估值/政策）→ 調整倉位
- **AI 技術判斷**：先有「這個技術有潛力」的先驗，看 benchmark 結果 → 調整信心
- **人生決策**：先有「該結婚」假設，相處過程 → 持續更新

## 常見誤用

- ❌ 過度反應新證據（給予過高權重）
- ❌ 拒絕更新（確認偏誤的相反）
- ❌ 沒有基率（忽略背景發生率）

## 與其他模型的關係
- → 是**期望值**的機率校正器
- → 是**第一性原理**的數學化（量化更新過程）
- → 抵抗**過度自信**的最強武器
