## 🎯 核心論點

**財富邊界遠超傳統「錢」的認知。** 吳軍提出四類資產邊界：
- 不同資產 → 不同問題 → 不同策略
- 混淆類別 = 投資決策失誤的根源

---

## 📐 四類資產總覽

| 類別 | 核心 | 主要問題 | 工具 |
|------|------|---------|------|
| **1. 金融資產** | 錢 | 「能買什麼？」 | 投資組合 / 風險控制 |
| **2. 能力資產** | 技能 / 經驗 | 「能解決什麼問題？」 | 學習 / 實踐 |
| **3. 信仰資產** | 世界觀 / 信念 | 「為什麼而活？」 | 哲學 / 修行 |
| **4. 共識資產** | 社會認同 / 關係 | 「誰跟我站一起？」 | 品牌 / 信任 / 社群 |

---

## 🔑 關鍵洞察

### 1. 資產邊界遠超傳統認知
- 多數人只關注類別 1（金融資產）
- 真正富足的人 = 四類資產都有積累
- **單一類別極大化 = 失衡**（有錢但無能 / 有能但無信 / 有信但孤獨）

### 2. 共識 / 信仰是第 3 / 4 類
- 信仰資產決定你**為誰做事**
- 共識資產決定**誰願意跟你做事**
- 兩者比金融資產更難複製

### 3. 不同資產問不同問題
- **類別 1：** 風險/收益/流動性
- **類別 2：** 天花板/可遷移性/稀缺性
- **類別 3：** 真理性/可證偽性/生命力
- **類別 4：** 信任成本/網絡效應/復購率

---

## 💎 投資策略含意

### 組合思維
```
四類資產總值 = 個人「真實淨值」

例：
  金融 1,000 萬 + 能力稀缺 + 信仰堅定 + 共識深廣
  > 金融 10,000 萬 + 能力平凡 + 信仰混亂 + 關係薄弱
```

### 風險維度
- **金融風險**：市場波動（可控）
- **能力風險**：技能過時（可補）
- **信仰風險**：信念崩塌（難救）
- **共識風險**：關係背叛（不可逆）
