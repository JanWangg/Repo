# 🏛️ 05 — Insights 宮殿

> **核心問題：我洞察了什麼世界/人生的底層邏輯？**

## 這座宮殿為何存在？

Knowledge 是別人的智慧，Insight 是**自己的智慧**。
本宮殿是從「資料 → 資訊 → 知識 → 智慧」的最後一里路。

## 內容分類

| 類別 | 說明 | 範例 |
|------|------|------|
| **底層邏輯** | 對世界運作規律的洞察 | 複利效應、熵增定律 |
| **人性洞察** | 對人類行為的洞察 | 損失厭惡、社會認同 |
| **自我洞察** | 對自身盲點的覺察 | 過度自信、確認偏誤 |
| **跨域洞察** | 把 A 領域搬到 B 領域 | 生物演化 ↔ 商業競爭 |
| **時空洞察** | 對時間/空間尺度的覺察 | 10 年視角 vs 10 天視角 |

## 洞察生成 5 步

```
觀察（看見現象）
  → 發現（辨識模式）
  → 關聯（連結既有知識）
  → 啟發（產生新理解）
  → 下一步（轉化為行動）
```
