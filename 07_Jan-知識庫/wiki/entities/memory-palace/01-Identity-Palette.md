# 🏛️ 01 — Identity 宮殿

> **核心問題：我是誰？我相信什麼？我為何而活？**

## 這座宮殿為何存在？

Identity 宮殿是**信念源頭**，所有其他宮殿（學習、決策、洞察）的根基。
沒有清楚的 Identity，再多知識也會失焦。

## 內容分類

| 類別 | 說明 | 範例 |
|------|------|------|
| **價值觀** | 我堅信的核心原則 | 誠實 > 利益、長期 > 短期 |
| **人生原則** | 引導行為的底層規則 | 家族利益優先、紀律是愛 |
| **長期目標** | 10年以上的方向 | AGI 時代的智慧工作者 |
| **人設定位** | 我想成為什麼樣的人 | 守護者/老師 |
| **底層假設** | 對世界的基本看法 | 技術決定論 vs 人文主義 |

## 核心信念（v1.0）

```
1. 家族利益優先
2. 紀律是愛
3. 系統勝於勤奮
4. 智慧 = 決策品質
5. 知而不行等於不知
6. 真正有價值的資產是「判斷力」而非「模型」
```
