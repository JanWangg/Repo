# 系統思維引擎 — 6 步推理流 ⚙️

> 將複雜問題拆解為 6 個連續步驟，**看見系統才能找對槓桿點**
> 整合 Donella Meadows 系統思維 + Karpathy LLM 思維鏈 + 達里歐 原則

## 一句話定義
**E → P → S → M → L → A** 是把混亂問題轉化為可行動方案的標準推理鏈。

---

## 6 步推理流（圖解）

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│ E 事件   │ → │ P 模式   │ → │ S 結構   │
│ Event    │   │ Pattern  │   │ Structure│
└──────────┘   └──────────┘   └──────────┘
                                    ↓
┌──────────┐   ┌──────────┐   ┌──────────┐
│ A 行動   │ ← │ L 槓桿點 │ ← │ M 心智   │
│ Action   │   │ Leverage │   │ 模式     │
└──────────┘   └──────────┘   └──────────┘
                 Mental
                 Model
```

## 各步驟詳解

### **E — Event 事件**
> 「發生了什麼？」

```
- 客觀描述事實（不含情緒）
- 時間、地點、人物、數據
- 區分「事件」與「對事件的解讀」

範例：
  「2026-06-22，NVDA 股價單日下跌 8%」
  （不是「NVDA 完蛋了」）
```

### **P — Pattern 模式**
> 「這是偶發還是規律？」

```
- 這個事件之前發生過嗎？
- 頻率多高？週期多長？
- 是否與其他事件相關？

範例：
  「NVDA 過去 5 年有 12 次單日跌幅 > 5%，
   平均 2.4 個月一次，之後 30 天平均反彈 +12%」
```

### **S — Structure 結構**
> 「什麼規則/迴路導致這個模式？」

```
- 找出增強迴路（什麼讓它加劇？）
- 找出調節迴路（什麼讓它穩定？）
- 識別延遲（因果之間隔多久？）
- 找到湧現（整體 > 部分之和？）

範例：
  「NVDA 波動結構：
   - 增強：AI 熱潮 → 大量買入 → 價格上漲 → 媒體報導 → 更多買入
   - 調節：估值過高 → 機構減持 → 價格回落
   - 延遲：基本面變化到股價反映約 3-6 個月
   - 湧現：整個 AI 產業生態的繁榮」
```

### **M — Mental Model 心智模式**
> 「結構為什麼是這樣被設計的？背後的信念是什麼？」

```
- 結構是誰設計的？為什麼這樣設計？
- 結構設計者的核心假設是什麼？
- 假設是否過時？
- 有沒有更合理的替代假設？

範例：
  「市場參與者的心智模式：
   - 假設：AI 是新工業革命 → NVDA 是核心受惠者
   - 替代假設：AI 泡沫即將破裂
   - 我的判斷：兩個假設都部分對，須持續驗證」
```

### **L — Leverage Point 槓桿點**
> 「小改動觸發大效果的位置在哪？」

```
Donella Meadows 提出的 12 槓桿點（從低到高）：
  12. 常數/參數（最弱，治標）
  11. 緩衝庫存大小
  10. 物料-調節迴路
   9. 延遲長度
   8. 調節迴路強度
   7. 增強迴路強度（贏家通吃）
   6. 資訊流結構
   5. 系統規則
   4. 自組織能力
   3. 系統目標
   2. 系統觀念（世界觀）
   1. 超越範式（最難，但改變一切）

範例：
  「對 NVDA 的槓桿點：
   - 我無法改變市場結構
   - 但我可以改變自己的持倉比例（L7-8）
   - 與進出時機的決策流程（L6-7）」
```

### **A — Action 行動**
> 「我要做什麼具體行動？」

```
- 對應到具體槓桿點
- 設定可衡量指標
- 設定時間表
- 設定反饋與調整機制

範例：
  「我的行動：
   - 將 NVDA 從 25% 減倉至 18%
   - 加碼 ASML 至 15%（分散 AI 風險）
   - 30 天後重新評估
   - 若 NVDA 反彈至前高，重新檢視結構變化」
```

## 何時使用？

| 場景 | 必經步驟 | 可跳過步驟 |
|------|---------|-----------|
| 重大投資決策 | 全部 6 步 | 無 |
| 日常交易 | E→P→L→A | S、M 簡化 |
| 個人職涯規劃 | 全部 6 步 | 無 |
| 突發事件應對 | E→P→A（OODA 替代） | S、M、L |
| 系統設計 | 全部 6 步 | 無 |

## 與其他模型的整合

```
E → P → S → M → L → A
         ↓       ↓     ↓
   系統思維  第一性  期望值
   風險矩陣  原理    機會成本
                    安全邊際
```

---

## ⚠️ 五大陷阱

1. **停在 E**：只看事件就行動（治標）
2. **跳過 S**：直接想對策（沒看見結構）
3. **卡在 M**：哲學辯論沒完沒了
4. **假槓桿點**：改變低槓桿位置（L12-9）
5. **不行動**：分析癱瘓，沒有 A

---

## 📋 操作檢查清單

```
□ 我清楚描述了事件（E）嗎？
□ 我找到了至少 1 個模式（P）嗎？
□ 我看見了結構中的迴路（S）嗎？
□ 我理解了心智模式（M）嗎？
□ 我找對了高槓桿點（L）嗎？
□ 我設定了具體可衡量的行動（A）嗎？
```
