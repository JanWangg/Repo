# 心智模型庫總覽 🧠

## 🎯 何時用哪個模型？

```
面對問題
  ↓
是「該做什麼」嗎？          → 期望值 / 機會成本 / 風險矩陣
  ↓
是「該怎麼做」嗎？          → PDCA / OODA / 系統思維
  ↓
是「怎麼想清楚」嗎？        → 第一性原理 / 逆向思考 / 貝氏思維
  ↓
是「怎麼不死」嗎？          → 安全邊際 / 反脆弱 / 黑天鵝
  ↓
是「怎麼突破」嗎？          → TOC / 複利效應
```
