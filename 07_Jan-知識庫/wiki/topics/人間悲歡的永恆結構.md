> **六百年過去了，《喻世明言》裡的人間悲歡，今日仍在重演。**

馮夢龍（1574–1646）的短篇小說揭示了**跨越時代的人類敘事原型**。

---

## 📐 三大原型

### 1. 窮人變富（階層流動）
- 經典：《賣油郎獨佔花魁》《金玉奴棒打薄情郎》
- 結構：出身卑微 → 機遇 + 努力 + 品德 → 翻身
- **現代版**：創業故事、底層逆襲、學歷翻身

### 2. 情侶重逢（命運糾葛）
- 經典：《蔣興哥重會珍珠衫》《范鰍兒雙鏡重圓》
- 結構：分離 → 誤解 / 災難 → 重逢
- **現代版**：愛情長跑、失聯重逢、電影重逢戲

### 3. 警惡勸善（因果報應）
- 經典：《沈小霞相會出師表》《滕大尹鬼斷家私》
- 結構：惡人作惡 → 短期得逞 → 最終敗露
- **現代版**：犯罪實錄、政治醜聞、企業敗局

---

## 🔍 永恆的結構性原因

### 為什麼這三類故事反覆出現？

| 維度 | 解釋 |
|------|------|
| **生物學** | 人類大腦天生愛「改變 vs 持續」的故事 |
| **社會學** | 階層流動是真實焦慮，愛情是真實需求，公義是真實盼望 |
| **心理學** | 故事 = 處理集體焦慮的儀式 |
| **經濟學** | 這三類故事的供需永不消失 |

## 💎 跨域啟發

### 1. 內容創作
- **永恆主題 > 流行話題**
- 任何熱門 IP 的底層都是這三原型
- 哈利波特 = 窮人變富 + 警惡勸善
- 漫威電影 = 警惡勸善 + 情侶重逢
- **AI 生成故事**：用這三原型當骨架，永不離題

### 2. 商業模式
- 賭博 / 投資 = 窮人變富的現代儀式
- 交友軟體 = 情侶重逢的數位版
- 法庭直播 / 犯罪實錄 = 警惡勸善的當代劇場
- **不變的人性 = 不敗的商業**

### 3. AI 時代的敘事
- AI 生成的故事容易「結構正確但情感空洞」
- **原因**：AI 學到形式，沒學到集體焦慮
- 真正打動人的故事 = 原型 × 時代焦慮

### 4. 個人成長
- 你的人生也是這三原型的組合
- 你的目標設定 = 哪個原型你正在追？
- **自我敘事的覺察 = 自由的第一步**

## 🛡️ 反思：原型的陷阱

### 窮人變富 → 可能誤導
- 故事只給結果，不給成本
- 成功 = 機遇 × 努力 × 品德 × 系統
- **現代過度消費此原型 → 焦慮世代**

### 情侶重逢 → 浪漫化災難
- 故事美化分離的痛苦
- 現實中大部分分離 = 真的結束
- **避免用「重逢」期待綁架現在**

### 警惡勸善 → 因果迷信
- 現實中惡人不一定受罰
- 把故事當現實 = 認知失調
- **接受世界的非對稱性**
