# 💻 ASIC 自研晶片趨勢

> CSP 大廠自研 AI 晶片，對 NVIDIA 的結構性威脅

## 核心趨勢

主要雲端服務提供商（CSP）正在加速開發自有 AI 晶片，以降低對 NVIDIA GPU 的依賴。這是對整個 AI 硬體供應鏈最具破壞性的結構性變化之一。

## 主要玩家動態

| CSP | 自研晶片 | 用途 | 最新動態 |
|-----|---------|------|---------|
| Google | **TPU v7** | 訓練 + 推理 | 大量內部使用，外部雲端可用 |
| Amazon | **Trainium3 / Inferentia3** | 訓練 / 推理 | AWS 全力推動 |
| Microsoft | **Maia 100 / Cobalt 100** | 推理 / 通用 CPU | Azure 部署中 |
| Meta | **MTIA v2** | 推理 | 自家推薦系統 |
| Tesla | **Dojo D1** | 自動駕駛訓練 | 規模化中 |

## 市場份額預測

| 年份 | ASIC AI 伺服器佔比 |
|------|------------------|
| 2026 | 27.8% |
| 2030 | **~40%**（TrendForce 預測） |

這意味著每 3 台 AI 伺服器中，約 1 台使用 ASIC；到 2030 年，這個比例接近一半。

## 對 NVIDIA 的影響

**並非非此即彼**：
- 通用 GPU（通用性、軟體生態）仍是大模型訓練主流
- ASIC 擅長特定場景（推理、性價比優化）
- NVIDIA 的护城河：CUDA 生態、NVLink 互聯、完整軟體棧

**長期風險**：
- 若 ASIC 性價比持續提升，NVIDIA Data Center 份額可能從 80%+ 逐步下滑
- 但訓練側壁壘更深，取代難度極高

## 對投資的啟示

- **受益方向**：半導體設備（TSMC 先進封裝仍需要）、HBM 需求（ASIC 同樣需要 HBM）
- **需要關注**：NVIDIA 的定價權是否受到衝擊
- **台灣供應鏈**：創意（世芯-KY）、智原、M31 是 ASIC 設計服務受益者
