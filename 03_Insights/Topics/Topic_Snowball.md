# ❄️ Snowball 自動化收入系統

> 雪球型被動收入 / 系統化收入設計

## 核心概念

Snowball（雪球）收入系統的核心理念：**初期播種，逐步擴大，最終形成自動運轉的現金流引擎**。類似滾雪球——一開始需要用力推，但雪球越大，滾動越快，最終無需太多外力就能持續壯大。

## 設計原則

### 1. 階梯式構建
```
第一階段：建立最小可行收入流（MVR）
  ↓ 驗證後
第二階段：規模化 + 多元分散
  ↓ 達到臨界點後
第三階段：被動化 / 半自動化
```

### 2. 收入類型分層

| 層級 | 類型 | 特性 | 對應技能 |
|------|------|------|---------|
| 🔵 基礎層 | 知識變現 | 一次性產出，持續銷售 | 寫作、課程設計 |
| 🟡 增值層 | 工具 / 訂閱 | 持續維護，週期收費 | 程式開發、系統設計 |
| 🔴 高階層 | 系統 / 平台 | 半自動運轉，睡後收入 | 產品化、AI 自動化 |

### 3. 槓桿化原則

- **時間槓桿**：一次性內容 × 多次分發
- **技術槓桿**：AI 自動化 → 減少邊際成本
- **資本槓桿**：被動收入 → 再投資

## 執行框架

### Phase A：發現（Discovery）
- [ ] 盤點自身核心能力（知識、技能、資源）
- [ ] 研究市場需求與變現路徑
- [ ] 識別 3 個潛在收入流

### Phase B：驗證（Validation）
- [ ] 最小可行產品（MVP）測試
- [ ] 目標：3 個月內驗證 1 個可變現方向
- [ ] 指標：轉化率 > 1%（Cold）或 > 10%（Warm）

### Phase C：擴張（Expansion）
- [ ] 規模化已被驗證的收入流
- [ ] 建立多元化收入組合
- [ ] 引入被動/半自動化機制

## 與投資的關係

Snowball 收入系統與價值投資有天然的協同：
- 收入系統產生自由現金流
- 現金流再投入 → 形成投資複利
- 投資組合又產生被動收入
- 兩者共同構築財務護城河
