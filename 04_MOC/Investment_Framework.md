# 投资框架 (Investment Framework)

## 六维风控体系

```
投资决策
    │
    ├── 📊 宏观      → 利率/通胀/地缘/政策
    ├── 🏢 企业      → 竞争优势/管理层/现金流
    ├── ⚙️ 系统      → 市场结构/流动性/相关性
    ├── 💧 流动性    → 持仓/杠杆/期权希腊值
    ├── 📈 估值      → PE/PB/PS/折现现金流
    └── ⚠️ 尾部风险  → 黑天鹅/肥尾/止损机制
```

## 投资工具箱

### 雪球结构
- 标的: 中证500 / 沪深300 / 个股
- 敲入/敲出价格设计
- 适合: 中性市+波动市
- 风险: 追保/本金损失

### 行业配置
- AI/半导体: 长期成长 (5-10年)
- 原材料: 周期+通胀对冲
- 现金: 等待机会

### 仓位管理
| 风险等级 | 单标的上限 | 总仓位上限 |
|---------|-----------|-----------|
| 高 | 10% | 40% |
| 中 | 20% | 60% |
| 低 | 30% | 80% |
