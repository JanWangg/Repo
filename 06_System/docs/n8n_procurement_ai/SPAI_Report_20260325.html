⚠️ 需要 Jan 確認的關鍵問題

  1. 委外延誤件的真實成本是多少？（目前假設 $5,000/件）
  2. IT 建置人時是 internal cost 還是外包行情？
  3. n8n 部署在哪裡？（公司內部 VM 還是雲端？）
  4. $7.87B 採購額是含稅口徑？
  5. Pilot 的第一個據點，建議選哪一個？（松江/昆山/泰國）
  6. 第一個參加 Pilot 的採購員，是否有人自願？
  7. T100 API 文件是否完整？（影響 Phase 2 整合難度）
  8. Domino 是否已啟用 IMAP？（若未啟用，需要管理員開通）
  9. 公司的 LLM API 預算用哪一個？（Claude / GPT-4o / MiniMax）
