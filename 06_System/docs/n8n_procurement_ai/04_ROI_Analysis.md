## 📐 ROI 評估框架

```
┌─────────────────────────────────────────────────┐
│              投資報酬率（ROI）評估               │
│                                                   │
│  ROI% = （年度效益總和 - 專案總成本）÷ 專案總成本 × 100%  │
│                                                   │
│  回收期（月）= 專案總成本 ÷ 月均效益             │
└─────────────────────────────────────────────────┘
```

## 3. ROI 試算（使用 AOP 實際數據）

### 3.1 方案 A（4-6 週 Pilot）ROI

```
【方案 A：Pilot → Year 1 完整 ROI】

一次性投資（Year 0）：
  Pilot 建置成本：              $772,000
  Year 1 維護成本：             $552,000
  ─────────────────────────────
  Year 0 總投入：             $1,324,000

Year 1 總效益（基準估算）：
  年度效益合計：            $118,000,000

Year 1 淨效益：
  $118,000,000 - $1,324,000 = $116,676,000

ROI（Year 1）：
  $116,676,000 ÷ $1,324,000 × 100% = 8,812%

投資回收期：
  $1,324,000 ÷ ($118,000,000 ÷ 12) = 0.13 個月（約 4 天）

Year 3 累計效益（維護成本 Year 2-3 不變）：
  Year 1：$118,000,000 - $1,324,000 = $116,676,000
  Year 2：$118,000,000 -   $552,000 = $117,448,000
  Year 3：$118,000,000 -   $552,000 = $117,448,000
  ─────────────────────────────────────────────
  3 年累計淨效益：                       $351,572,000

3 年平均 ROI：($351,572,000 ÷ 3) ÷ $1,324,000 = 8,852%
```

```
→ 委外OTD改善幅度取決於 Phase 2 能否完整串接委外系統
```

```
【關鍵變數：Cost Reduction 談判改善幅度】

2025 年實際 Cost Reduction = 0.75%（$59M）
AI 若能將談判成功率再提升：

┌──────────────────────────────────────────────────────────────┐
│  情境         AI額外提升  額外節省    年度總效益      ROI   │

→ 這個數字取決於：AI 是否能讀取並分析談判歷史數據
```

```
【悲觀情境底線測試】

若以下三個最壞情況同時發生：
✗ 委外OTD 改善幅度僅 +5%（遠低於預期）
✗ Cost Reduction 完全無改善（談判已到天花板）

年度總效益仍有：
  $58.9M（樂觀的50%）= $29.4M
```

## 8. ROI 評估結論與建議

```
【結論】

✓ 方案 A（4-6 週 Pilot）
  ROI 8,812%（基準）/~4,350%（保守），回收期 < 1 個月
  → 高度建議立即推動
  → 主要效益來自：委外OTD改善（56%→70%）+ PO OTD改善 + PR→PO效率

✓ 方案 B（完整版）
  ROI 4,503%（基準），回收期 < 1 個月
  → Pilot 成功後滾動擴展至 Phase 2（委外）+ Phase 3（Cost AI）

【最大紅利來自：委外OTD】
2025 年委外 OTD 僅 56%，落後目標（90%）34個百分點，
這是整張 AOP 表中落後幅度最大的指標，也是 AI 最大的切入點。

每改善委外OTD 1個百分點 ≒ 1,399件 減少延誤 ≒ $4.2M/年
改善 14個百分點（56%→70%）≒ $58.7M/年

【最大風險】
唯一真正的風險不是「ROI 不佳」，而是「來不及建置」。
建議盡快啟動 Pilot，先串委外OTD追蹤模組（Phase 2 最快見效）。

【需 Jan 確認的三個數字】
① 委外延誤件的真實成本（目前假設 $3,000/件）→ 是否符合實際？

③ 2025 年採購額 $7.87B 是含税口徑？

| Domino IMAP 不通   | 中    | 申請專用測試環境驗證            |
| AI Free Text 解析  | 中    | Pilot 前先做 20 封真實 mail 測試 |
```
